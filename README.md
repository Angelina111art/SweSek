# Angelina Osinska — Academic Portfolio

A bilingual (Ukrainian / English) personal portfolio and Sweden economic-security report microsite.\n
## Files
- `index.html` — author profile
- `sweden.html` — economic security overview of Sweden, 2014–2024
- `css/style.css` — responsive styling
- `js/main.js` — language switcher and content data
- `js/charts.js` — Chart.js visualizations
- `assets/profile.jpg` — supplied profile photo

## Run locally
Open `index.html` in a browser. Chart.js charts require internet access to load the CDN library. The pages and basic layout work without the chart library.


## Publish
Upload the project files and folders to your GitHub repository and enable GitHub Pages from repository Settings → Pages. Choose deployment from the main branch/root if using the standard repository setup.


## Data note
Sweden statistics and assessment levels are reproduced from the author's academic report, "Оцінювання рівня економічної безпеки держави (на прикладі Швеції)," covering 2014–2024. The values have not been independently verified. Charts intentionally use only explicit endpoints or reported year values; no annual intermediate values are fabricated.
